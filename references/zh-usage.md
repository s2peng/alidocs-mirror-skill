# 钉钉知识库镜像 Skill 中文使用说明

这个 Skill 用来把钉钉 / 阿里文档知识库中的一个节点，按照页面里的文件夹结构，镜像保存到本地指定文件夹。

## 适合什么时候用

- 用户给出一个 `alidocs.dingtalk.com` 的知识库或节点链接。
- 用户给出一个本地保存位置，例如 `<本地保存路径>`。
- 用户希望保留线上目录结构，批量下载文件。
- 用户希望把微信推文链接保存成 PDF。
- 用户希望在已有 PDF 后，删除对应的链接说明文本。

## 如何触发这个 Skill

最稳的方式是在需求开头直接写 Skill 名：

```text
$alidocs-mirror 帮我把这个钉钉知识库链接镜像到 <本地保存路径>，保留目录结构，微信推文保存成 PDF，有 PDF 的 txt 链接文件就删掉。
```

如果用户不写 `$alidocs-mirror`，Codex 也会根据 `SKILL.md` 里的描述做语义判断。下面这些中文表达都应该视为强触发信号：

- 镜像钉钉知识库
- 下载阿里文档知识库
- 把 alidocs.dingtalk.com 链接保存到本地
- 保留线上文件夹结构
- 批量下载钉钉文档资料
- 微信推文保存成 PDF
- 有 PDF 后删除 txt 或 `.url.txt` 链接文件

注意：这些不是硬编码关键词规则，而是给 Codex 判断任务意图用的语义提示。对外分享时，仍建议直接使用 `$alidocs-mirror`，避免跑偏。

## 用户只需要提供什么

通常只需要两项：

1. 钉钉知识库链接
2. 本地保存路径

如果浏览器还没有登录钉钉，先让用户在浏览器里登录，然后再继续。

## 执行规则

- 优先使用已经登录的浏览器会话。
- 按知识库页面中的文件夹结构创建本地目录。
- 文件优先通过列表右侧的三个点菜单下载。
- 如果菜单下载失败，再尝试从预览页下载。
- 普通网页链接会保留为本地链接说明。
- 微信公众号文章链接会尽量另存为 PDF。
- 如果链接已经成功保存成 PDF，就可以删除对应的 `.url.txt` 或旧版文本占位文件。

## 输出内容

镜像完成后，本地目录通常会包含：

- 下载得到的原始文件。
- 微信文章转成的 PDF。
- `_alidocs_tree.json`：线上目录结构记录。
- `_mirror_report.md`：下载结果报告。
- `_在线文档与链接入口索引.md`：无法直接下载或需要保留入口的链接索引。

## 完成后要检查什么

- 是否有下载失败的文件。
- 是否还有未处理的目录。
- 是否还有 `.url.txt` 文件。
- 微信推文 PDF 是否能正常打开，不是空白页或登录页。
- 索引文件里是否只保留了确实需要保留的在线入口。

## 典型说法

用户可以这样提需求：

> $alidocs-mirror 帮我把这个钉钉知识库链接镜像到 `<本地保存路径>`，微信推文保存成 PDF，有 PDF 的链接文本就不用保留。

Codex 应该按上述规则自动完成镜像、PDF 转换、清理和检查，并在最后汇报下载数量、PDF 数量、失败项和剩余链接。
