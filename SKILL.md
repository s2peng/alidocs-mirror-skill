# AliDocs Mirror

Use this skill to mirror a DingTalk/AliDocs knowledge-base node into a local folder using the current signed-in browser session.

The primary user scenario is Chinese. Treat requests like "镜像钉钉知识库", "下载阿里文档知识库", "保存到本地文件夹", "保留目录结构", "微信推文转 PDF", and "有 PDF 就删除 txt 链接文件" as strong signals to use this skill.

The intended user input is just:

- source AliDocs node URL
- local output folder

The workflow preserves the visible folder structure, downloads files through the list-page three-dot menu, falls back to preview download when needed, writes local reports, converts WeChat article links to PDF, and removes link text placeholders when a PDF copy exists.

For Chinese human-readable usage notes, read `references/zh-usage.md` when the user asks how to use or share this skill.

## Required Setup

Use the browser skill with a signed-in AliDocs/DingTalk page. If the user is not signed in, ask them to sign in and tell you when ready.

Use `node_repl` for the browser-driven mirror. Before importing scripts that need Playwright from Node, add the bundled Node modules directory when available:

```js
await mcp__node_repl.js_add_node_module_dir({
  path: "<bundled-node-modules-path>"
});
```

If the bundled dependency path is unknown, call `codex_app.load_workspace_dependencies()` and use its Node modules path.

## Standard Workflow

1. Open or claim the AliDocs URL in the signed-in browser.
2. Import `scripts/alidocs_browser_mirror.mjs`.
3. Run `mirrorAliDocsFromBrowser` with `rootUrl`, `outDir`, and the claimed `tab`.
4. Import `scripts/postprocess_link_entries.mjs`.
5. Run `postprocessAliDocsLinkEntriesFromBrowser` for the same `outDir`.
6. Verify reports and local files:
   - `_alidocs_tree.json`
   - `_mirror_report.md`
   - the online-link index generated by the scripts
   - no `.url.txt` remains when a corresponding webpage PDF exists
7. Report counts, remaining non-PDF links, and any failures.

## Mirror Script

Import the mirror script from this skill folder:

```js
var urlMod = await import("node:url");
var pathMod = await import("node:path");
var skillDir = "<absolute path to installed alidocs-mirror skill folder>";
var mirrorScriptUrl = urlMod.pathToFileURL(pathMod.join(skillDir, "scripts", "alidocs_browser_mirror.mjs")).href + "?run=" + Date.now();
var mirrorMod = await import(mirrorScriptUrl);
var mirrorResult = await mirrorMod.mirrorAliDocsFromBrowser({
  tab: alidocsTab,
  rootUrl: "https://alidocs.dingtalk.com/i/nodes/...",
  outDir: "C:\\path\\to\\target-folder",
  overwrite: true,
  skipExisting: false,
  progress: (event) => {
    // Optional: keep recent progress for status updates.
  }
});
```

Use `skipExisting: true` only for a resume run after a partial mirror. For the first complete mirror, use `skipExisting: false`.

The mirror script:

- identifies the right-side main file list, avoiding the left navigation tree
- navigates folders by node URL instead of relying on double-click behavior
- downloads files through each row's right-side three-dot menu
- falls back to preview download if menu download fails
- writes `.url.txt` only for entries that are not direct downloadable files

## Link PDF Postprocessing

After mirroring, run:

```js
var linkScriptUrl = urlMod.pathToFileURL(pathMod.join(skillDir, "scripts", "postprocess_link_entries.mjs")).href + "?run=" + Date.now();
var linkMod = await import(linkScriptUrl);
var linkResult = await linkMod.postprocessAliDocsLinkEntriesFromBrowser({
  tab: alidocsTab,
  outDir: "C:\\path\\to\\target-folder",
  includeLegacyTextEntries: false,
  deleteTextWhenPdf: true
});
```

Rules:

- Convert `mp.weixin.qq.com` links to PDF and save beside the link entry.
- Delete the corresponding `.url.txt` or legacy text entry when the PDF exists.
- Keep non-WeChat links as text entries, because dynamic websites, photo live albums, and online directories may not render reliably as complete PDFs.
- Update the online-link index with converted PDF links and remaining non-PDF links.

For old mirrors that used `.txt` or extensionless text entries instead of `.url.txt`, run with:

```js
includeLegacyTextEntries: true
```

## Verification

After every run, check:

```powershell
Get-ChildItem -LiteralPath "<outDir>" -Recurse -Filter "*.url.txt"
rg -n "\\[linked\\]|\\.url\\.txt|linked entries" "<outDir>\\_mirror_report.md" "<outDir>\\*_index.md"
Get-ChildItem -LiteralPath "<outDir>" -Recurse -File | Group-Object Extension | Sort-Object Name
```

For generated PDFs, render at least the first page of representative PDFs with Poppler (`pdftoppm`) and visually inspect that the PDF is not blank or blocked by a login/interstitial page.
